# D3 — папка для имитации занятости

Статус: модель готова к подключению; пользовательский путь не включён.

## API и состояние

- createDisguise() возвращает JSON-состояние shiftId/nextAttemptId/used/active/lastOutcome.
- beginDisguise(state, context) требует shiftId, printerAvailable, action, paused и shiftEnded; начинает двухсекундную подготовку при доступном принтере и action=none.
- tickDisguise(state, dt, context) во время подготовки требует action=takeFolder. По завершении переводит в active с 12 секундами и used=true. После этого таймер продолжает идти даже при остановке; пауза его замораживает. Если подготовку прервали, заряд не расходуется.
- canDisguiseCover(state, context) требует moving, action, конечный bossDistance, isRaid, paused и shiftEnded. Возвращает true только при активной папке, рейде, moving=true, action=none, расстоянии строго больше 34 и без паузы/конца смены. Она не меняет state, рабочий статус или видимость.
- cancelDisguise(state, reason) завершает папку без наград; активная папка расходует заряд, отменённая подготовка — нет. reason: cancel/rest_started/shift_ended.

## Проверки

- node scripts/qa-parallel-d3.js — подготовка/отмена, JSON reload, пауза, остановка, рейд/обычный режим, расстояние 34, действие отдыха, разовый заряд и истечение.
- node --check js/disguise.js — успешно.
- node scripts/qa.js — выполняется после завершения пакета.
- Визуальная проверка не нужна: renderer и Canvas не менялись; папку рисует адаптер A.

## Подключение

A передаёт доступность принтера и классифицированное action; модель не меняет playerIsWorking, suspicion, visibility или рендер и не использует игровые globals.
