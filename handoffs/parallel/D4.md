# D4 — память Д.Н.

Статус: модель готова к подключению; изменение поведения начальника не включено.

## API и состояние

- createBossMemory() создаёт JSON state shiftId/recordedCount/seenIncidentIds/observations.
- observeBossIncident(state, context) принимает только incidentType caught или autoclicker_exposed с visible=true и safeSpot={x,y}. Записывает безопасную точку на 60 игровых секунд; максимум два разных incidentId за смену. Невидимые события, неизвестный тип, повтор и третья запись отклоняются.
- tickBossMemory(state, dt, context) требует paused; время уменьшается только когда paused=false, истёкшие точки удаляются. recordedCount остаётся на месте, поэтому истёкшие записи не восстанавливают лимит смены.
- chooseRememberedSpot(state, context) требует текущий shiftId, normalStroll=true, availablePointIds (проверенные интегратором по геометрии/маршруту) и randomSample 0..1. При sample < 0.35 выбирает первую доступную незанятую точку, помечает consumed и возвращает requestBossRoute + message. В остальных случаях маршрут не запрашивается.
- Цель маршрута — targetId записи; точная координата остаётся в сериализуемом state и возвращается в DTO. effect requestBossRoute не вызывает bossGoTo и не обходит проверки A.

## Подключение

A сообщает только наблюдённое нарушение, подбирает safeSpot, фильтрует availablePointIds и вызывает выбор при обычном обходе. Если путь не проложен, A оставляет обычную patrol-точку; модель не проверяет коллайдеры и не усиливает vision/speed/suspicion.
