# Agent handoff

## Текущий статус

Версия `0.6.0`, играбельный анимированный прототип. `index.html` открывается без сборки и сервера, а также развернут на GitHub Pages ([statsenko-na.github.io/ne-palysya](https://statsenko-na.github.io/ne-palysya/)). Игровые PNG локальные; `style.css` дополнительно импортирует Google Fonts и при отсутствии сети использует моноширинный fallback. Проект синхронизирован с GitHub-репозиторием [`statsenko-na/ne-palysya`](https://github.com/statsenko-na/ne-palysya); локальная ветка `main` отслеживает `origin/main`.

## Сделано

- **Покадровая анимация ходьбы**: горизонтальные 4-кадровые спрайт-листы `assets/vikentiy-walk-v1.png` и `assets/fedor-walk-v1.png` (2048×512), динамическое отражение спрайтов влево/вправо (`flipX`), покачивание хвостика Викентия, грузная поступь начальника и частицы шагов.
- **Коллеги за компьютерами**: Айаршын, Влад, Александр и Глеб сидят прямо в офисных креслах за своими столами перед мониторами (`feetY = 214`, `chairY = 207`), анимированы руки на клавиатурах, бейджи вынесены на верхнюю перегородку столов.
- **GitHub Pages CI/CD**: настроен `.github/workflows/pages.yml` для автоматического развертывания при пуше в `main`.
- Canvas 960×540 с детальным фоном карты Алматы (1672×941).
- Управление WASD/E/H/P на обеих раскладках (латиница и кириллица `ЦФЫВ`/`У`/`Р`/`З`).
- Подсветка интерактивных зон, укрытия в монстере, фикусе и архивных шкафах, кофемашина, курилка, лог событий.

## Проверки

- Проверка синтаксиса JavaScript через headless Edge (`new Function`) — `STATUS_OK`.
- Визуальный рендеринг проверен через снимки экрана в headless Edge: коллеги сидят за мониторами, персонажи анимированы, интерактивные подсказки видны.
- Все ассеты локальные, относительные пути корректны для GitHub Pages.
- Нужна отдельная проверка нажатия и отпускания клавиш в браузере на обеих раскладках; в текущей среде браузерная проверка этой правки не выполнялась.
- Страница с `#play` открыта локально в браузере; Canvas проверен визуально после последней сборки: фон, атлас коллег, игрок, начальник, HUD и интерактивные маркеры отображаются.
- Локальный preview отдал все PNG/SVG-ассеты без ошибок; в консоли страницы ошибок не было.
- В браузере проверены действие Excel (`E`), пауза (`P`) и отображение состояния тревоги/проверки. Движение и укрытие (`H`) отдельно не подтверждены.
- Повторный браузерный запуск через `file://` заблокирован URL-политикой инструмента; сцену проверял через локальный preview. В проекте не добавлялись серверные зависимости.

## Ограничения

- Общий фон — один растровый слой с уже нарисованной мебелью; персонажи поверх него и могут перекрывать часть стола. Для точной окклюзии потребуется разделить карту на пол и передний слой мебели.
- Визуальная геометрия зоны не создаёт физические препятствия: персонажи пока могут пересекать часть мебели.
- Аудио синтезируется через Web Audio API; внешних звуковых файлов нет.
- Баланс и маршрут начальника находятся в `game.js`, отдельного конфига нет.
- Полноразмерная версия остаётся в разрешении Canvas 960×540; для ещё большей лицевой детализации нужны увеличенные/анимированные игровые кадры, а не только источник PNG.

## Следующие полезные шаги

1. Проверить управление, укрытия и исход проверки после нового старта в браузере, включая русскую раскладку.
2. Если потребуется ещё больше глубины сцены, разделить фон на пол и переднюю мебель с корректной окклюзией персонажей.
3. Добавить несколько кадров ходьбы для отдельных спрайтов и проверить текст на обычном размере пользовательского окна.
4. Вынести баланс и маршрут патруля в отдельный конфиг, если сценариев смены станет больше.
