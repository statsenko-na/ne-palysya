# Agent handoff

## Текущий статус

Версия и её состав — в [`VERSION.md`](../VERSION.md) и [`CHANGELOG.md`](../CHANGELOG.md). `index.html` открывается без сборки и сервера; деплой на GitHub Pages идёт через `.github/workflows/pages.yml` при пуше в `main`; на сайт попадают только `index.html`, `style.css`, `game.js`, `js/` и ассеты, на которые ссылается код (репозиторий [`statsenko-na/ne-palysya`](https://github.com/statsenko-na/ne-palysya), Pages: [statsenko-na.github.io/ne-palysya](https://statsenko-na.github.io/ne-palysya/)).

## Архитектура

| Файл | Что внутри |
| --- | --- |
| `js/world.js` | Геометрия: стены, коллайдеры мебели, зоны, растения, узлы навигации, точки обхода |
| `js/lines.js` | Все реплики: цитаты Директора, диалоги с коллегами, мысли Быкентия, задачи дня |
| `js/config.js` | Баланс и данные: `CFG`, сложность, апгрейды, `DAYS`, открытие механик по дням |
| `js/art.js` | Процедурный рендер офиса в offscreen-холсты 2× + спрайты мебели с `baseY` |
| `game.js` | Цикл, ввод (с переназначением клавиш), звук, коллизии, A*-подобный поиск пути, ИИ, события, HUD, телефон, обучение, `NP_DEBUG` для автотестов |
| `scripts/qa.js` | Автотест в headless Chromium (проверки + скриншоты в `.qa/`) |
| `scripts/screens.js`, `pw.js` | Скриншоты на 6 экранах; поиск установленного Playwright |
| `scripts/make_panorama.py` | Вид на Алматы из `office-background-pixel-v1.png` |
| `scripts/make_boss_walk.py` | Цикл ходьбы Д.Н. (`boss-walk-v3.png`) из торса `boss-walk-v2.png` |
| `scripts/replace_sprite.py`, `pixel_processor.py` | Замена ячейки листа спрайтов из сгенерированной картинки, обработка пиксель-арта |

Скрипты подключаются в `index.html` по порядку: world → lines → art → config → game. `NP_DEBUG` доступен только под автотестом или с `?debug`.

После правок: `node --check` для `game.js` и `js/*.js`, затем `node scripts/qa.js`.

## Ограничения

- Звук синтезируется Web Audio; в headless не проверялся на слух.
- Соседи второго ряда и люди в очереди в туалет не имеют коллизий.
- Кресла второго ряда и мелкая мебель не имеют коллизий (только столы, шкафы, МФУ, стойки, горшки и т.п.).
- Баланс настроен по автотестам и коротким прогонам; нужен живой плейтест всей недели.
