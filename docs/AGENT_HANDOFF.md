# Agent handoff

## Текущий статус

Версия `0.19.0` — Альджазира (Начальник Маджикистана), саркастичные диалоги и офисный цинизм, строгий лимит кайфа 100 с индикацией `100 MAX`, ограничение кулера на 4 стакана с перезарядкой 30 минут, реалистичная кофемашина (варка 2.8 с, утренние очереди, засор жмыхом с починкой на +3 KPI), закрытие микрозадач и пулов в Excel (+4 и +10 кайфа), снятие выговора за сверхурочные при выполненном плане, ад-хоки от руководства, недельный накопитель выговоров и балансировка сложности (стажёр: 4/7, сотр.: 3/5, ветеран: 2/4), автосохранение прогресса смены в `localStorage`; 0.18.1 — удобная посадка за рабочий стол спереди и сзади, чистый экран без спама тостов; 0.18.0 — персонажи по фото сотрудников, статист Штази; 0.17.0 — Д.Н. гуляет по офису; 0.16.1 — компактные окна; 0.16.0 — масштабирование текста; 0.15 — «Не пались», Тигран. `index.html` открывается без сборки и сервера; деплой на GitHub Pages идёт через `.github/workflows/pages.yml` при пуше в `main` (репозиторий [`statsenko-na/ne-palysya`](https://github.com/statsenko-na/ne-palysya), Pages: [statsenko-na.github.io/ne-palysya](https://statsenko-na.github.io/ne-palysya/)).

## Архитектура

| Файл | Что внутри |
| --- | --- |
| `js/world.js` | Геометрия: стены, коллайдеры мебели, зоны, растения, узлы навигации, точки обхода |
| `js/lines.js` | Все реплики: цитаты Директора, диалоги с коллегами, мысли Быкентия, пул дел |
| `js/art.js` | Процедурный рендер офиса в offscreen-холсты 2× + спрайты мебели с `baseY` |
| `game.js` | Цикл, `CFG` (баланс), `DAYS` (неделя), ввод, звук, коллизии, A*-подобный поиск пути, ИИ, события, HUD, телефон, обучение, `NP_DEBUG` для автотестов |
| `scripts/qa.js` | Автотест в headless Chromium (75 проверок + скриншоты в `.qa/`) |
| `scripts/make_characters.py` | Пиксельные правки персонажей v3 (Быкентий, Аймашын, второй ряд) |
| `scripts/normalize_sprites.py`, `face_edit.py`, `make_panorama.py` | Пайплайн ассетов v1 → v2 |

Скрипты подключаются в `index.html` по порядку: world → lines → art → game.

## Ограничения

- Звук синтезируется Web Audio; в headless не проверялся на слух.
- Лица на v2-спрайтах отредактированы программно. При большом увеличении на месте очков и усов видна гладкая заливка; в игровом масштабе незаметно. Идеально — перегенерировать исходники без очков и усов.
- Соседи второго ряда и люди в очереди в туалет не имеют коллизий.
- Аймашын собран из кадра Блеба, поэтому поза похожа (кадр отзеркален). Идеально — сгенерировать отдельный исходник.
- Кресла второго ряда и мелкая мебель не имеют коллизий (только столы, шкафы, МФУ, стойки, горшки и т.п.).
- Баланс настроен по автотестам и коротким прогонам; нужен живой плейтест всей недели.

## Следующие полезные шаги

1. Живой плейтест недели и подстройка `CFG`/`DAYS`.
2. Перегенерировать исходные спрайты Быкентия (рокер без очков) и Директора (без усов) и прогнать пайплайн.
3. Добавить ещё событий (пожарная тревога, «корпоратив», проверка из ЦБ) и реплик в `js/lines.js`.
4. Отдельные анимации «сидит/печатает» вместо стоячего кадра за столом.
