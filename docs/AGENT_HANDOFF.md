# Agent handoff

## Текущий статус

Версия `0.5.1`, играбельный локальный прототип. `index.html` открывается без сборки и сервера. Игровые PNG локальные; `style.css` дополнительно импортирует Google Fonts и при отсутствии сети использует моноширинный fallback. До этой задачи история Git в каталоге отсутствовала; теперь создан локальный репозиторий на `main` с первым коммитом, но приватный репозиторий GitHub ещё не создан.

## Сделано

- Canvas 960×540 с новым детальным PNG-фоном карты Алматы размером 1672×941.
- Отдельные прозрачные PNG-спрайты Викентия и Федора Павловича; отдельный атлас четырёх коллег 2×2.
- Видимые имена и роли коллег; верхние интерактивные зоны, укрытия и стартовые позиции подогнаны под фоновую карту.
- Локальная эмблема-щит; UI использует стилизованное имя «Фирдом Банк» без словесного логотипа.
- Механики смены и управления описаны в `GAMEPLAY.md`; визуальная система и происхождение растровых файлов — в `ART_DIRECTION.md`.
- WASD/E/H/P приведены к физическим позициям и дополнены кириллическим fallback (`ЦФЫВ`/`У`/`Р`/`З`); управление обновлено в игровом README и документации механик.
- Проверены официальные OpenAI материалы по skills, MCP и hooks, официальный каталог Codex skills и GitHub MCP Server; рекомендации записаны в `AGENT_TOOLING.md`. Antigravity/Gemini и GitHub CLI в этой среде не обнаружены.
- Ветка `main` подготовлена: 19 файлов проекта добавлены в начальный локальный коммит. Перед добавлением настроен `.gitignore`; секрет-pattern scan совпадений не нашёл.
- Публикация ждёт ручного входа пользователя: GitHub CLI, credential helper и токен в окружении отсутствуют, браузерная вкладка показывает страницу входа. Внешняя репозитория пока нет, push не выполнялся.
- Обновлены `AGENTS.md`, `OPENAI_CODEX_GUIDE.md`, версия и changelog. В агентских рекомендациях нет закреплённого имени модели: игра не использует API, а модель Codex/API следует проверять под конкретную задачу.

## Ограничения

- Общий фон — один растровый слой с уже нарисованной мебелью; персонажи поверх него и могут перекрывать часть стола. Для точной окклюзии потребуется разделить карту на пол и передний слой мебели.
- Визуальная геометрия зоны не создаёт физические препятствия: персонажи пока могут пересекать часть мебели.
- Аудио синтезируется через Web Audio API; внешних звуковых файлов нет.
- Баланс и маршрут начальника находятся в `game.js`, отдельного конфига нет.
- Полноразмерная версия остаётся в разрешении Canvas 960×540; для ещё большей лицевой детализации нужны увеличенные/анимированные игровые кадры, а не только источник PNG.

## Следующие полезные шаги

1. Войти в GitHub в открытой вкладке, затем создать приватный репозиторий и отправить туда проект. Пока вкладка показывает форму входа; репозиторий не создан и файлы не загружались.
2. Проверить управление, укрытия и исход проверки после нового старта в браузере, включая русскую раскладку.
3. Если потребуется ещё больше глубины сцены, разделить фон на пол и переднюю мебель с корректной окклюзией персонажей.
4. Добавить несколько кадров ходьбы для отдельных спрайтов и проверить текст на обычном размере пользовательского окна.
5. Вынести баланс и маршрут патруля в отдельный конфиг, если сценариев смены станет больше.
