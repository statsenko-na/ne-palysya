## Как вести документацию

1. Сначала обнови код и проверь его.
2. Затем обнови документ, который описывает изменённую область.
3. Добавь запись в `CHANGELOG.md`, если пользовательское поведение, визуал или структура изменились.
4. Если изменился способ запуска или управление, обнови `README.md`.
5. Не копируй сюда длинные логи и не дублируй весь исходный код: документы должны объяснять решения и правила.
