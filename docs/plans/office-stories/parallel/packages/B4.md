## Результат и API

Предлагаемые функции верхнего уровня: resolveReducedEffects, getEffectPresentation.
До начала проверить отсутствие конфликтующего объявления в своей базе. Уже согласованные имена не переименовывать молча.
Чистая настройка: resolveReducedEffects(savedBooleanOrNull,mediaPreferenceBoolean) и getEffectPresentation(reduced,{shake,flash,danger}). Возвращать амплитуду визуальных эффектов и статический сигнал опасности; не читать matchMedia/store/DOM, это делает A. Сохранённое false сильнее системного true. UI, CSS, draw подключит A.
