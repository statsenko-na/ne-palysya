## Шаги и правила

1. Участники: только aimashyn/hlad/shurik/bleb/sirgey, присутствующие и открытые. Тигран, статисты и Альджазира не входят в «всех».

2. Состояния idle -> inviting(10 с) -> assembling(12 с max) -> smoking(7 с) -> returning -> done/caught/cancelled. Пригласить можно после 10:30 и до 16:30, вне обеда/события учений/daily.

3. Список eligible фиксировать при приглашении; минимум 3. angry отказывает, остальные принимают без расхода favorCredit. Статус отказа виден.

4. Для достижения «Весь отдел на перекуре» требуется >=4 приглашённых eligible, все они дошли и полностью закончили smoking без обнаружения. Удалённый Сиргей не нужен до ЧТ; нельзя получить за одного друга.

5. Вход в smoking только при прибытии всех согласившихся и игрока; таймаут -> отмена без наград, всем вернуть маршрут.

6. До обнаружения уход игрока/обед/учения отменяет группу; после обнаружения caught нельзя отменить выходом или меню.

7. Сохранить cohort, accepted/refused, arrived, timers, detected, outcomeApplied. Один запуск на смену, отказ всей группы тоже расходует запуск.
