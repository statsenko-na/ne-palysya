## Шаги и правила

1. В телефон добавить «Позвать на перекур», сначала показать cohort и возможные отказы. Не перемещать NPC телепортом; пока mobile, обычный idle/slack/scold не управляет тем же NPC.

2. На месте игрок получает обычные 4 кайфа/с (смог 2.4), без дополнительного chat/perk. По успешному завершению максимум moment groupSmoke и достижение; cigarettes++ ровно один раз.

3. Д.Н. обнаруживает группу только через свою геометрию видимости хотя бы одного участника на балконе непрерывно 1.2 с. Не требовать видимости Быкентия: инициатор всегда виноват. За стеной не видит, стекло по текущим правилам прозрачно.

4. caught: один обычный reprimand за организацию, −12 кайфа инициатору, все согласившиеся angry до конца следующего дня, отправить всех обратно, реплика «Быкентий собрал? Быкентий и ответит!».

5. coverTokens может снять формальный выговор, но не −12 и обиду. Не умножать выговор по числу коллег; не вызывать обычный caught дополнительно для того же эпизода.

6. При камерном обнаружении игрока применять существующий камерный выговор и переводить группу в caught без второго выговора; −12/обида однократно. Уход Д.Н. не гарантирует защиту от СБ.

7. При конце смены/эвакуации восстановить статусы NPC без зависшего away. Достижение только после успешных 7 с, не за приглашение.

8. Для достижения сравнить всех исходных eligible, включая отказавших: нельзя сократить cohort после отказа ради ачивки. При отказах перекур разрешён, достижение недоступно.
