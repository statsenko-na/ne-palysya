## Шаги и правила

1. В памяти до 2 точек observedSlack за смену: записывать точку только при caught или видимом раскрытии автокликера. Не записывать скрытого игрока, невидимый клик и сохранённый путь.

2. В следующем обычном обходе с вероятностью 0.35 выбрать доступную точку рядом с наблюдением; использовать rand, не Math.random. Не подменять проверку стола и не идти сквозь коллайдер.

3. Память живёт 60 игровых секунд и затем удаляется. При выборе реплика «Я уже видел, где тут отдыхают». Нет увеличения vision/speed/suspicion.

4. Для одинакового отвлечения лимит уже установлен 13, не создавать второе независимое наказание.

5. Сохранить remainingSeconds и координату безопасной навигационной точки. На новую смену сбросить.

6. Проигрыш маршрута возвращает обычную patrol-точку. Не раскрывать HIDDEN и не выдёргивать игрока из растения.
