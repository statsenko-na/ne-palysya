## Шаги и правила

1. Создать маршруты для aimashyn/hlad/shurik/bleb/sirgey от прохода перед столом к пяти допустимым слотам балкона и обратно. Сидячий sprite с креслом нельзя просто двигать по полу.

2. Сначала процедурный прототип: узнаваемая верхняя часть без кресла только если можно корректно выделить; иначе процедурное тело с существующими цветами и подписью имени. Нельзя изменять исходные spritesheets без отдельной задачи ассетов.

3. Слоты вычислить по фактической геометрии, проверить круг каждого персонажа через blocked и соединение findPath. Не придумывать координаты вслепую в ТЗ.

4. Движение по dt, разворот, небольшой шаг ног, сигарета и дым процедурно. Глубина сортируется по ногам, у стола корректный переход seated/mobile.

5. В debug-сцене показать каждого отдельно и пять одновременно, статические Canvas снимки. Не запускать бот-недели и не покупать генерацию изображений.

6. Результат — go/no-go по читаемости и проходимости с конкретными скриншотами; если визуал неприемлем, описать точные нужные ячейки/размеры будущих ассетов и остановить 32 до их подготовки.

- [ ] Не проходит мебель/стекло.
- [ ] вход/выход балкона.
- [ ] два встречных NPC.
- [ ] возврат.
- [ ] нет кресел, скользящих по полу.
- [ ] узнаваемость на 960×540 и мобильном размере.
- [ ] Выполнены общие проверки из COMMON.md; новые игровые исходы проверены адресными сценариями.
- [ ] Обработаны новая смена, отмена, пауза, загрузка, конец смены и отсутствие зависимого NPC.
- [ ] Задача не меняет катастрофу Альджазиры, обязательную бытовую рутину и старые покупки.
- [ ] Результат соответствует описанию, а не только отсутствию исключений.
