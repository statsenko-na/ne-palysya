## Шаги и правила

1. API openActionChoice({id,owner,options,expiresIn}), closeActionChoice(reason), selectActionChoice(index). В сериализуемом состоянии только id/owner/options ids/timer, никаких callback-функций в save.

2. Handlers регистрируются явно в action-choice по id; неизвестный id закрывается безопасно. Повтор нажатия не повторяет оплату/эффект.

3. Существующую летучку не переписывать: новые выборы не открываются при choice.asked && !choice.done. Во вводе сначала активный новый выбор, потом answerStandup.

4. Цифры 1/2/3, Numpad и клики по одним и тем же hitboxes; действия с буквами EN/RU оставить. Esc закрывает выбор первым, повторный Esc ставит паузу.

5. Мир продолжает идти; P — пауза, все таймеры выбора используют dt. Движение закрывает обычный выбор без оплаты; будущий daily-вопрос имеет собственное правило ухода.

6. Показать цену/риск коротко под вариантом. Disabled вариант объясняет причину. UI не перекрывает HUD/сенсорные кнопки, использует UI-масштаб проекта.

7. В этой задаче добавить только debug-пример, не выставлять фиктивные действия в обычной игре.
