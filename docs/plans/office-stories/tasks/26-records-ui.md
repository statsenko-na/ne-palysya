## Шаги и правила

1. Поле «Кто сегодня Быкентий?» до 20 символов, последнее имя сохранено. Пустое допустимо; Enter запускает игру только после штатной обработки поля, WASD в поле не двигают персонажа и не открывают меню.

2. Фиксировать имя, difficulty и ruleset при новой смене; изменение меню при resume не переименовывает прошлую. autoUsed липкий: включил хотя бы раз -> assisted даже после выключения/загрузки.

3. auto.demo никогда не создаёт рекорд; отдельно проверить, что демонстрация не меняет playerName/таблицу. Начальные деньги/покупки в demo здесь не менять без дополнительной задачи.

4. Экран топ-10 с фильтрами дня/сложности/с помощью. Подпись «Рекорды в этом браузере» обязательна, не обещать онлайн.

5. Имя выводить textContent или Canvas T, не innerHTML. Новые данные не ломают старый best.

6. Записать результат один раз после окончательного расчёта. Кнопка закрытия, клавиатура, прокрутка и mobile landscape.
