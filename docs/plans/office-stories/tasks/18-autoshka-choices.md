## Шаги и правила

1. При autoshka Сиргей просит помощь. Вариант «Оставить разбираться» сохраняет текущее отвлечение Д.Н., без нового штрафа.

2. Вариант «Помочь нормально»: 6 непрерывных секунд у стола Сиргея, палево как chat, при завершении +6 plan через addWork, credit Сиргея и moment colleagueHelp. Кайф за эти 6 с не начислять.

3. Вариант «Быстрый костыль»: 3 с, +3 plan, без credit и moment. Через 12 игровых секунд один раз −6 plan (не ниже 0), реплика «Костыль отвалился»; сохранить pendingFailure, выполнить после обеда, даже если базовое событие уже закончилось.

4. Варианты запускаются только если в событии достаточно времени на 6/3 с; завершение после истечения не даёт награды. Сиргей away/remote — помощи нет.

5. Помощь не обрывает уже выданную нотацию Д.Н. Новое действие не меняет поведение катастрофы Альджазиры.

6. Одна завершённая ветка на событие, никакого переключения после выплаты.

## Проверяемая приёмка

- [ ] Три ветки.
- [ ] прерывание.
- [ ] событие закончилось.
- [ ] поздняя поломка после reload.
- [ ] обед.
- [ ] Сиргей удалённо.
- [ ] plan около 0/полного.
- [ ] однократный credit.
- [ ] Выполнены общие проверки из COMMON.md; новые игровые исходы проверены адресными сценариями.
- [ ] Обработаны новая смена, отмена, пауза, загрузка, конец смены и отсутствие зависимого NPC.
- [ ] Задача не меняет катастрофу Альджазиры, обязательную бытовую рутину и старые покупки.
- [ ] Результат соответствует описанию, а не только отсутствию исключений.
