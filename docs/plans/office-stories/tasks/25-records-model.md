## Шаги и правила

1. API normalizePlayerName(raw), makeRecord(input), addLocalRecord(state,record), listLocalRecords(state,filter). Имя trim, схлопнуть пробелы, 1..20 Unicode code points; пустое -> «Быкентий», управляющие символы удалить.

2. Запись: runId, name, score, dayIndex, difficulty, rulesetId, autoUsed, maxTimeScale, completedAt, outcome. Не включать IP/устройство/настоящие личные сведения.

3. Разделять difficulty, ruleset и manual/assisted; demo не записывать. Победные смены сортировать score desc, затем completedAt asc; максимум 10 на категорию и максимум 300 всего.

4. runId уникален на новую смену и сохранён; повтор записи того же id заменяет/игнорирует, а не дублирует.

5. Старые best.day не удалять и не подписывать новым именем: отдельное «Старый рекорд, правила 0.24.1».

6. Повреждённую таблицу восстанавливать до валидных записей. Никаких сетевых запросов и токенов GitHub.
