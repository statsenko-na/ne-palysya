## Шаги и правила

1. API createRelationships(ids), applyRelationshipEvent(state,{eventId,npcId,kind,dayIndex}), canRequestFavor(state,npcId,dayIndex), consumeFavor(state,npcId,dayIndex), advanceRelationshipsDay(state,nextDay).

2. Для aimashyn/hlad/shurik/bleb/sirgey: mood neutral/friendly/angry, favorCredit 0..1, angryThroughDay, helpedDay, favorUsedDay. Тигран и статисты не участники первой версии.

3. Помощь один раз конкретному коллеге в день: friendly и credit=1. Обычная болтовня сама по себе кредит не даёт.

4. Предательство: angry до конца следующего дня, credit=0. Извинение из конкретной истории снимает angry, но не создаёт credit. Услуга требует credit=1, не angry, не использована сегодня.

5. На новый день переносить отношения, а на новую неделю сбрасывать. При переигровке дня восстановить снимок отношений на начало дня; при продолжении смены — текущий снимок.

6. Обработка eventId идемпотентна. При нескольких причинах обиды продлевать до максимального срока, а не бесконечно прибавлять дни.
