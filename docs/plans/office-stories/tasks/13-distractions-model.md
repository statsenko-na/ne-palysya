## Шаги и правила

1. API createDistractions(), canDistract(state,context,kind), beginDistraction(state,context,kind,target), tickDistraction(state,dt,context), finishDistraction(state,reason).

2. kind printer или colleague. Всего максимум 2 успешных отвлечения в смену, cooldown 45 игровых секунд с завершения; одинаковый kind только один успешный раз.

3. В допустимом контексте Д.Н. office/patrol/look/return — сверить фактическое имя look в коде и записать в handoff; исключить все инспекции, нотацию, уход, обед, эвакуацию, летучку/daily, отдых после наказания.

4. Жизненный цикл idle -> walking -> occupied(6 с) -> done; walking максимум 12 с, нет маршрута -> failed без списания доступного использования. Вход begin только после успешного построения пути.

5. Достижение момента distraction не по клику: игрок должен завершить отдых, пока Д.Н. занят этой конкретной приманкой. Источник = shiftId+attemptId.

6. Повторная заявка при активной приманке отклоняется. Состояние сериализуемое, никакого таймера браузера.
