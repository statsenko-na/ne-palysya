## Шаги и правила

1. API createMoments(), awardMoment(state,id,sourceId), summarizeMoments(state). Каталог: variety=3, distraction=3, colleagueHelp=3, story=3, groupSmoke=3. Общий потолок 12, каждый id максимум раз за смену.

2. sourceId служит идемпотентности; повтор события после загрузки не повторяет выплату. Не выдавать монеты, кайф, достижения или план из этого модуля.

3. variety требует завершить четыре разных отдыха из smoke/youtube/fridge/chat/phone; phone учитывается после непрерывных 6 с, простое открытие справки не считается.

4. Прерванные действия, ходьба рядом и повтор одного отдыха не дают variety. Для phone хранить накопление текущего эпизода, сбрасывать при выходе.

5. Данные и русские подписи результатов хранить в модуле как не-диалоговые строки; реплики персонажей в LINES.

6. Сводка возвращает начисленное и достижимый остаток потолка. Старый save -> пустой журнал.
