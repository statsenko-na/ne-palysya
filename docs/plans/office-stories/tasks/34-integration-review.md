## Шаги и правила

1. Составить перечень реально включённых модулей и правил. Не считать существование файла завершённой фичей: проверить подключение, точку входа, save, cancel, UI, автопилот.

2. Сверить таблицу расходов/доходов BALANCE.md с кодом. Измерить детерминированные отдельные сценарии: обычная работа, тихий отдых, риск, помощь, две покупки, штрафы. Не устраивать бот-недели вне обязательного scripts/qa.js.

3. Основная формула +12 moments, без бесплатного addFun. Награда «история» максимум одна; каждый эффект имеет стоимость/ограничение.

4. Если явная доминирующая стратегия: сначала сократить эффект/заряд/частоту, затем рассматривать план +5 в повторных неделях. Не повышать всё одновременно, не менять катастрофу Альджазиры.

5. Проверить старый v2 save, новые save между релизами, монеты/покупки, ручные/assisted/demo рекорды, EN/RU, file:// и статический запуск.

6. Обязательные node --check и scripts/qa.js; целевые тесты новых модулей и реальные Canvas snapshots. Отдельно написать, что человеческий баланс не подтверждён без живого плейтеста.

7. Сделать changelog/version для собранной волны, проверить согласованность cache query в index/ASSET_V по принятому релизу.
