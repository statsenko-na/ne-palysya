# Приёмка PR и итогового релиза

## Для каждой карточки

- Область изменения соответствует карточке; нет соседнего незапрошенного рефакторинга.
- Зависимости слиты, предложенные API сверены с их фактическим handoff.
- Каждая кнопка имеет работающий исход; недоступная объясняет причину.
- У действия проверены start, cancel, done, pause, resume, newDay, finish.
- Не начисляется награда за отмену или повторную загрузку.
- Один и тот же incident не выдаёт два выговора/кредита/момента.
- Состояние сохраняется полностью; JSON round trip не теряет Set, id и pending outcome.
- Нет геймплейных setTimeout, случайности в draw или повторного множителя timeScale.
- Есть ограничения на частоту, заряды, размер коллекций.
- EN/RU и касания работают одинаково; ввод имени не вызывает игровые действия.
- Автопилот использует разрешённые действия, не застревает в новом меню. Дополнительные бот-плейтесты без просьбы не запускались.
- Обязательные проверки действительно выполнены, stderr/exit code изучены.
- Скриншоты реального Canvas просмотрены, а не только сохранены.
- Тексты GAMEPLAY/ART_DIRECTION и changelog соответствуют включённым фичам.
