Статус: модель готова к подключению; интерфейс и пользовательский путь в игре не включены.

## Основа

- Base SHA: b44686b63ea798f0090c4a3a8f5767dcf23feec4.
- Исходные карточки: 11, 12, 16.
- Обычный smoke занимает 7 секунд, youtube — 8, fridge — 4.5; updatePlayer начисляет обычные rates отдельно, а endAction увеличивает соответствующие счётчики. Модель эти глобальные функции не меняет.

## API и состояние

- createActivities() возвращает JSON-состояние с shiftId, nextAttemptId, active, listeningCompleted, intelGranted, yogurtStolen.
- startActivityVariant(state, context, variant) поддерживает smoke-listening, youtube-quiet, youtube-loud, fridge-own, fridge-yogurt. Для инсайда требуются dayIndex >= 1 и ordinarySmokeCompleted; YouTube требует internetAvailable; йогурт требует ownerAvailable и storyAvailable.
- tickActivityVariant(state, dt, context) получает уже симуляционный dt. Контекст всегда содержит paused и shiftEnded; при пересечении третьей секунды громкого youtube также требует bossState, конечное bossDistance и bossRouteAvailable.
- Длительности/rate: listening 3/0; quiet youtube 8/5 (40); loud youtube 6/5.5 (33); fridge-own 4.5/3 (13.5); fridge-yogurt 4.5/4 (18). countAsBaseActivity=false только у прослушивания. Модель возвращает rate и не выдаёт addFun.
- На громком youtube active.noiseTriggered сохраняется до или после перезагрузки. На дистанции до 220 включительно доступное состояние Д.Н. возвращает requestBossRoute к server; busy/unrouteable состояние — только message с lineId youtubeNoiseBlocked; далеко — без эффекта.
- finishActivityVariant(state, reason) завершает только при remaining=0 с reason done; cancelActivityVariant(state, reason) допускает отмену и конец смены без награды. Завершение listening даёт ровно один grantIntel на 20 секунд с combine=max; завершённое видео/еда дают countCompleted; завершённый йогурт также даёт startStory с storyId yogurt.
- Стабильные sourceId: shiftId:activity:attemptId; каждый эффект имеет уникальный id. Все функции чистые, state клонируется на переходах.

## Граница зависимости

Опция fridge-yogurt не запускается без storyAvailable=true; это охраняет зависимость задачи 17. Интегратор включает её только вместе с историей 17, а Friday objective должен читать yogurtStolen, не общий fridge.
