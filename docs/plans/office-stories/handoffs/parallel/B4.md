## Реализовано

- Сохранённое boolean-значение настройки имеет приоритет; при отсутствии/повреждении значения берётся boolean системного предпочтения.
- В reduced mode амплитуды Canvas shake и fullscreen flash равны нулю. Уровень опасности остаётся видимым статическим сигналом без пульсации; исходные уровни не меняются.
- Модель не обращается к `matchMedia`, store, DOM или Canvas и не меняет gameplay state.
- Изменённые файлы: `js/accessibility.js`, `scripts/qa-parallel-b4.js`, этот handoff. Новая настройка не подключена и пока не влияет на игрока.

## Контракт

- `resolveReducedEffects(savedBooleanOrNull, mediaPreferenceBoolean)` → boolean. Только явно сохранённые `true`/`false` выигрывают у системного выбора; отсутствующее/небулевое значение использует `mediaPreferenceBoolean === true`.
- `getEffectPresentation(reduced, { shake, flash, danger })` → `{ ok, reason, shake, flash, dangerLevel, dangerAlpha, dangerPulse, staticWarning }`. Ненормальные числовые значения сводятся к безопасному нулю; `dangerLevel` ограничен 0..1; `staticWarning` включён при danger >= 0.05. При `reduced:true` shake/flash=0, pulse=false, статическая видимость сохраняется.
- Пример: `getEffectPresentation(true,{shake:0.5,flash:0.9,danger:0.8})` → shake 0, flash 0, dangerLevel 0.8, статический красный сигнал. Неизвестный context возвращает `ok:false` и безопасные нули.
- Модель намеренно не возвращает значения suspicion, dt, скорости NPC, таймеров или звука. При подключении A получает их отдельно и не меняет.
- Script-тег — после `js/core.js` и до первого вызова; настройку/хранилище/media query подключает только A.
