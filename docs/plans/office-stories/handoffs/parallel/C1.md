# C1 — отношения коллег

Статус: модель готова к подключению. Исходная задача 07 не считается включённой в игру.

## Изменения и проверка

- `js/relationships.js` — чистая сериализуемая модель без обращения к NPC runtime, DOM, store или времени браузера.
- `scripts/qa-parallel-c1.js` — сценарии помощи, кредита, обиды, извинения, переходов дней, новой недели, повтора и JSON round trip.
- Проверка: `node scripts/qa-parallel-c1.js` — все утверждения пройдены.

## Фактический API

- `createRelationships(ids?)` — создаёт состояние для пяти допустимых id: `aimashyn`, `hlad`, `shurik`, `bleb`, `sirgey`. Без аргумента включает всех. Неизвестный id даёт `{ ok: false, reason: 'unknown_npc' }`.
- `applyRelationshipEvent(state, { eventId, npcId, kind, dayIndex })` — `kind`: `help`, `betrayal`, `apology`. Возвращает `{ ok, state, effects: [], reason }`. Повтор уже принятого `eventId` — успешный no-op. Помощь один раз в день выставляет `friendly` и кредит `1`; повторная помощь и помощь во время активной обиды отклоняются.
- `canRequestFavor(state, npcId, dayIndex)` — возвращает `{ ok, canRequest, reason }`; проверяет кредит, использованный сегодня кредит и активную обиду.
- `consumeFavor(state, npcId, dayIndex)` — атомарно возвращает новое состояние с кредитом `0` и `favorUsedDay`; недоступный кредит отклоняется без изменения входа.
- `advanceRelationshipsDay(state, nextDay)` — дни ПН–ПТ имеют индексы `0..4`. Обида действует до конца следующего дня; при пятничной обиде срок ограничен концом рабочей недели. Переход `4 → 0` начинает новую неделю и сбрасывает отношения и журнал eventId. Повтор дня следует делать из сохранённого dayStart snapshot, а не переводом индекса назад.

Состояние JSON-совместимо: `schemaVersion`, `dayIndex`, `npcIds`, `appliedEventIds`, `entries[id] = { mood, favorCredit, angryThroughDay, helpedDay, favorUsedDay }`. Входные состояния и объекты не мутируются. Неизвестный NPC/день или повреждённое состояние отклоняются со стабильным `reason`.

## Примеры

```js
const state = createRelationships();
const helped = applyRelationshipEvent(state, {
  eventId: 'shift-42:autoshka:help', npcId: 'sirgey', kind: 'help', dayIndex: 3,
});
canRequestFavor(helped.state, 'sirgey', 3);
// { ok: true, canRequest: true, reason: null }

applyRelationshipEvent(helped.state, {
  eventId: 'shift-42:unknown', npcId: 'tigran', kind: 'help', dayIndex: 3,
});
// { ok: false, state: helped.state, effects: [], reason: 'unknown_npc' }
```

## Интеграционные заметки

Адаптер A должен явно вызывать `advanceRelationshipsDay`, применять `relationship` эффекты атомарно и сохранять модель в extension `relationships`. Для повтора дня он восстанавливает dayStart snapshot. В модели нет UI, загрузки, сохранения или старых перков. Помощь во время активной обиды блокируется, чтобы помощь не обходила срок предательства; извинение из конкретной истории снимает обиду и не даёт кредит.
