## Реализовано

- Ограниченный журнал пяти категорий по 3 очка; общий потолок — 12. Одна выплата на категорию, повтор source не даёт повторной выплаты.
- Разнообразие отдыха учитывает четыре разных завершённых вида из `smoke`, `youtube`, `fridge`, `chat`, `phone`. Отменённый эпизод не учитывается. Для телефона модель накапливает симуляционные `dt` только пока эпизод активен и очищает счётчик при выходе; требуется не менее 6 секунд.
- Чистый расчёт очков: ограниченный кайф + полный план + дела + выговоры + бонус моментов; возвращаются breakdown, score, coins и существующая оценка.
- Изменённые файлы: `js/moments.js`, `scripts/qa-parallel-b1.js`, этот handoff.
- Модуль не подключён в `index.html`, не меняет пользовательское поведение, глобальные деньги, кайф, план, DOM или хранилище.

## Контракт

- `createMoments()` → `{ version, awards, variety }`; состояние сериализуется в JSON. Старое или отсутствующее `extensions.moments` адаптер может заменить значением `createMoments()`.
- `awardMoment(state, id, sourceId, context?)` → `{ ok, state, effects, reason }`. Для обычной категории адаптер вызывает функцию только после подтверждённого исхода. Для `variety` обязательный context: `{ activityId, active, completed, paused, dt? , shiftEnded? }`; `dt` нужен для активного телефонного эпизода, время паузы не прибавляется. ID эффектов имеют вид `${sourceId}:moment:${id}`.
- `summarizeMoments(state)` → `{ awarded, cap, remaining, moments }`; подписи категорий — данные результата, не диалоги.
- `calculateShiftResult({ fun, fullPlan, done, reprimands, momentBonus })` → `{ ok, breakdown, score, coins, grade, reason }`. `momentBonus` — число из `summarizeMoments(state).awarded`. `fun` ограничивается 0..100, бонус моментов — 0..12; score округляется после сложения и ограничивается снизу нулём. Пороги оценки сохранены: S 160, A 120, B 85, C 50, иначе D.
- Эффекты перехода не начисляют кайф и монеты напрямую; A применяет расчёт в одном месте после окончательных наказаний и результата смены.
- Пример: `awardMoment(createMoments(), 'distraction', 'shift-17:printer:done')` даёт 3 очка; `awardMoment(createMoments(), 'unknown', 'shift-17:x')` возвращает `ok: false, reason: 'unknown_moment'`. Четвёртый завершённый разный отдых может выдать `variety`; открытие/отмена не выдаёт бонус.
- Порядок подключения: после `js/core.js`, до первого вызова; integration owner A добавляет script-тег и жизненный цикл save/reset.
