## Фактический API

- `createYogurtStory()` — создаёт состояние `dormant`.
- `startYogurtStory(state, { shiftId, sourceId, clockMinutes, shiftEnded })` — принимает один факт кражи, переводит в `stolen`.
- `tickYogurtStory(state, { dt, paused, clockMinutes, legalAway, shiftEnded, ownerAvailable })` — обнаруживает пропажу после 10 симуляционных секунд; во время паузы, легального отсутствия или недоступности Хлада детектор ждёт. До 17:00 молчание истекает по `clockMinutes`. Если обнаружение произошло с 17:00, даётся 20 симуляционных секунд; конец смены закрывает неразрешённую историю.
- `chooseYogurtResolution(state, choice, { clockMinutes, shiftEnded, legalAway, ownerAvailable, blebFavorAvailable, coffeeCompletedAfterDiscovery })` — `choice`: `admit`, `bleb`, `silent`. Ветка `admit` лишь фиксирует выбор и ждёт отдельного завершения кофе. Ветка `bleb` при положительном кредите завершает историю и возвращает `consumeFavor`, `relationship` (извинение Хладу), `awardMoment` (`story`) и `message`.
- `completeYogurtCoffee(state, { clockMinutes, shiftEnded, legalAway, ownerAvailable, coffeeCompletedAfterDiscovery })` — завершает выбранную ветку признания только после новой варки и внешнего двухсекундного действия у стола Хлада. Возвращает извинение, момент `story` и сообщение; обычный кофейный boost модель не выдаёт.

Переходы возвращают `{ ok, state, effects, reason }`, не мутируют вход. Повтор уже завершённого исхода даёт `effects: []`. Форма state: `schemaVersion`, `status`, `shiftId`, `sourceId`, `startedAtClockMinutes`, `detectionElapsed`, `discoveredAtClockMinutes`, `responseSecondsRemaining`, `resolution`, `outcome`. Эффект ID строится из `shiftId`, источника кражи и результата, поэтому повтор после reload сохраняет ID.

## Примеры

```js
const started = startYogurtStory(createYogurtStory(), {
  shiftId: 'shift-17', sourceId: 'shift-17:fridge:1', clockMinutes: 900, shiftEnded: false,
});
const discovered = tickYogurtStory(started.state, {
  dt: 10, paused: false, clockMinutes: 900, legalAway: false, shiftEnded: false, ownerAvailable: true,
});
const blocked = chooseYogurtResolution(discovered.state, 'bleb', {
  clockMinutes: 901, shiftEnded: false, legalAway: false, ownerAvailable: true,
  blebFavorAvailable: false, coffeeCompletedAfterDiscovery: false,
});
// blocked.ok === false, blocked.reason === 'favor_unavailable'; discovered.state остаётся discovered.
```

## Предлагаемые реплики для LINES

- Хлад, обнаружение: «Мой йогурт пропал. В отделе рисковых кредитов завёлся рискованный холодильник.»
- Быкентий, мысль: «Я только посмотрел на крышечку. Очень внимательно.»
- Хлад, вопрос: «Быкентий, ты случайно не видел клубничный йогурт? Он был размером с твою совесть.»
- Хлад, признание и кофе: «Ладно, кофе принимается. Но крышечку я запомнил.»
- Блеб, прикрытие: «Скажем, что йогурт ушёл на тестирование. Кредит прикрытия — один.»
- Хлад, после Блеба: «Блеб, спасибо. Быкентий, холодильник теперь под наблюдением.»
- Хлад, срок истёк: «Я всё понял. На следующей неделе холодильник будет с двухфакторной аутентификацией.»

## Интеграционные заметки и ограничения

A передаёт `sourceId` завершённой кражи, `shiftId` и проверенные флаги доступности, применяет все эффекты результата атомарно и сохраняет состояние рядом с историей. Не отмечать воровство моментом: `story` выдаётся только за признание или услугу Блеба. При неуспешном `consumeFavor` адаптер не фиксирует новое состояние. Сброс истории при новой неделе делает адаптер созданием нового state. Текста в `js/lines.js`, UI, кофе-действия, сохранения и runtime-подключения этот пакет не добавляет.
