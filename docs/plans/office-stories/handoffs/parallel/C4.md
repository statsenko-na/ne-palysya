Статус: модели готовы к подключению. Исходная задача 24 не включена в игру.

## Фактический API

- `createWeekOutcomes(weekId?)` — создаёт чистый недельный архив. `weekId` — непустая строка или целое неотрицательное число.
- `recordWeekFact(state, { eventId, weekId, kind, value? })` — факты `help`, `betrayal`, `distraction`, `reprimand`, `fullPlan`, `majikArc` (конечный числовой `value`) и `munichEnding` (`value: true`). События дедуплицируются по `eventId`; другая неделя отклоняется как `week_mismatch`. Результат `{ ok, state, effects: [], reason }`.
- `selectWeekTitle(state)` — возвращает `{ ok, titleId, facts, reason }`. Приоритет `department_pillar` (>=3 помощи), `excuse_master` (иначе >=3 отвлечений), `boss_favorite` (иначе 0 выговоров и >=3 полных планов), `neutral`. `facts.summary` содержит три счётчика для итогового экрана; `facts.counts` и `facts.endings` сохраняют полную недельную сводку, включая факт Маджикистана и пятничного пива. Селектор не заменяет и не переписывает тексты существующих концовок.
- `createTigranSecret(weekId?)` — создаёт этап `dormant`.
- `advanceTigranSecret(state, action, context)` — `action`: `talk_complete`, `search_start`, `search_tick`, `search_cancel`, `return_talk_complete`, `new_week`. `weekId` обязателен в каждом context; старый weekId отклоняется, новую неделю нужно явно обозначить действием `new_week`.
  - `talk_complete`: требует `eventId`, `tigranAvailable`; один раз переводит `dormant → hinted` и возвращает `message`.
  - `search_start`: требует `eventId`, `playerAtArchive`, `bossThreat`, `legalAway`, `shiftEnded`; принимает только подсказанную историю в архиве без угрозы.
  - `search_tick`: требует `dt`, `paused`, `playerAtArchive`, `bossThreat`, `legalAway`, `shiftEnded`; три симуляционные секунды дают `found`. Пауза замораживает таймер; уход, угроза или легальное отсутствие возвращают в `hinted` без награды.
  - `search_cancel`: требует `eventId`, отменяет поиск без эффектов.
  - `return_talk_complete`: требует `eventId`, `tigranAvailable`, `storyMomentAvailable`, `legalAway`, `shiftEnded`; переводит `found → completed`, всегда возвращает финальное `message`, а `awardMoment` с `momentId: 'story'` — только если общий момент ещё доступен.
  - `new_week`: требует другой `weekId` и явно сбрасывает этапы и список eventId.

Результаты переходов — `{ ok, state, effects, reason }`, вход не мутируется, state проходит JSON round trip. Модели не обращаются к `player`, `boss`, NPC runtime, DOM или хранилищу. Прямого эффекта `addFun` или валюты нет.

## Примеры

```js
let state = createWeekOutcomes('week-1');
state = recordWeekFact(state, {
  eventId: 'shift-5:help:sirgey', weekId: 'week-1', kind: 'help',
}).state;
selectWeekTitle(state);
// { ok: true, titleId: 'neutral', facts: { ... }, reason: null }

const blocked = advanceTigranSecret(createTigranSecret('week-1'), 'search_start', {
  weekId: 'week-1', eventId: 'shift-5:archive:1', playerAtArchive: true,
  bossThreat: true, legalAway: false, shiftEnded: false,
});
// blocked.ok === false, blocked.reason === 'archive_hint_required'
```

## Предлагаемые строки и подписи

- `department_pillar`: «Опора отдела» — «На этой неделе Быкентий чаще чинил чужие проблемы, чем свои.»
- `excuse_master`: «Мастер отмазок» — «План горел, Д.Н. смотрел, а Быкентий всё равно находил выход.»
- `boss_favorite`: «Любимчик Д.Н.» — «Ни одного выговора и три полных плана. Начальник подозрительно доволен.»
- Нейтральный титул остаётся существующим.
- Тигран, подсказка: «В архиве где-то лежит старый пропуск. Я бы поискал, если бы мог вставать.»
- Быкентий, найденная улика: «Пропуск старше некоторых сервисов, но в учёте он ещё жив.»
- Тигран, финал: «Теперь у тебя тоже есть пропуск в историю. Не теряй.»

## Интеграционные заметки

A записывает входные weekly facts только по стабильным eventId, создаёт свежий архив при новой неделе и показывает недельный титул рядом с исходным текстом пятничной концовки. Для секрета A вызывает модель по завершению разговора/выбору у архива, сохраняя обычный `H` как укрытие. `storyMomentAvailable` должен учитывать общий лимит момента `story`, в том числе уже выданный йогуртом; если он недоступен, финальная реплика Тиграна всё равно завершается без второй награды.
