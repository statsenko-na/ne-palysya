## Реализовано

- У холодильника есть выбор: свой перекус — 4,5 с, 3 кайфа/с; йогурт Хлада — 4,5 с, 4 кайфа/с. Награда учитывает дневной множитель.
- Полностью завершённая кража увеличивает `stats.fridge` и `saveExtensions.activities.yogurtStolen`, запускает C2-историю и даёт одну реплику. Отмена ничего не засчитывает; повторный йогурт заблокирован, свой перекус остаётся.
- Пятничная цель `yogurt` читает флаг кражи, а не общий счётчик холодильника.
- Изменены: `index.html`, `js/interact.js`, `js/lines.js`, `js/meta.js`, документация задачи и игры; добавлен `scripts/qa-plan-16.js`.
- История подключена в том же интеграционном слоте по требованию карточки; отдельного релиза 16 без 17 нет.

## Контракт

- Используются функции замороженной модели D2: `startActivityVariant`, `tickActivityVariant`, `cancelActivityVariant`; новый общий API не добавлен.
- Варианты: `fridge-own` и `fridge-yogurt`; завершённый `fridge-yogurt` задаёт `yogurtStolen: true` и эффект запуска истории.
