# НЕ ПАЛИСЬ — банковский офисный симулятор

Офисный стелс-симулятор прокрастинации в top-down pixel-art. Главный герой — айтишник из отдела рисковых кредитов алматинского БЦ «Угар», который должен дожить до окончания смены в 19:30. Задача — сделать дневной план и кайфовать остальное время (кофе, перекуры с видом на горы, болтовня с коллегами, чужой холодильник), но сидеть в Excel ровно тогда, когда начальник Д.Н. смотрит в его сторону.

## Запуск

- **Онлайн (GitHub Pages):** [https://statsenko-na.github.io/ne-palysya/](https://statsenko-na.github.io/ne-palysya/)
  *(первое включение: **Settings → Pages → Build and deployment → Source: GitHub Actions**; деплой идёт при пуше в `main`).*
- **Локально:** дважды кликни по `index.html`. Сборка, сервер и зависимости не нужны.
- **Телефон:** в альбомной ориентации появляются виртуальный стик и кнопки.

## Управление

| Клавиши | Действие |
| --- | --- |
| `WASD` / `ЦФЫВ` / стрелки | Ходить (стены и мебель непроходимы) |
| `E` / `У` / `Пробел` | Действие у подсвеченного места: Excel, кофе, болтовня, перекур… |
| `H` / `Р` | Спрятаться: растение, шкафы архива, ксерокс |
| `Tab` / `Q` / `Й` | Телефон: список дел, бонусы, рабочий чат (смотреть в телефон — палево) |
| `P` / `З` / `Esc` | Пауза |
| `M` / `Ь` | Звук вкл/выкл |
| `U` / `Г` | Магазин апгрейдов (в меню и после смены) |
| `B` / `И` | Альт-таб — мгновенно сделать вид, что работаешь |
| `1` / `2` / `3` | Ответ Д.Н. на летучке |
| `N` / `Т` | Музыка вкл/выкл (отдельно от звуков) |
| `I` / `Ш` | «Как играть» — подробный онбординг |
| `Enter` | Начать смену / следующий день |

## Как играть

- **Цель:** сделать план на день, накайфоваться и не получить 3 выговора до 19:30.
- **План.** Excel даёт работу к плану, на глазах у Д.Н. — вдвое быстрее. Сверх плана работа почти ничего не даёт — выгоднее кайфовать. Не сделал план к 19:30 — выговор.
- **Конус обзора.** Жёлтый конус перед Д.Н. — его взгляд. Прокрастинируешь в нём — растёт «?», на 100% — выговор.
- **Проверки стола.** «Кхм-кхм…» — Д.Н. идёт к твоему столу. Стол пустой — он ждёт: «ГДЕ БЫКЕНТИЙ? 3…2…1». Не успел — «не застал на месте» +1; на лимите (Стажёр 6, Сотрудник 5, Ветеран 3) — выговор.
- **Неделя ПН–ПТ.** Механики открываются постепенно: со вторника коллеги, со среды обед в «Мюнхене» и биотуалет с очередью, с четверга второй ряд, летучка и Маджикистан, в пятницу Д.Н. уезжает в 17:00, а в «Мюнхене» пиво.
- **Коллеги.** Подойди к столу и нажми `E` — у каждого свой бонус.
- **События:** угощение, сбор на ДР, жара, перфоратор, учения, летучка, падение интернета, ксерокс, камеры СБ, смог и пробки на Аль-Фараби.
- **Сложность** (Стажёр / Сотрудник / Ветеран), **достижения** 🏆, **апгрейды** за KPI-коины, **автопилот** 🍿 и ползунок скорости времени.
- **Любой экран.** Текст в игре подстраивается под размер экрана (от телефона до 4K), меню прокручиваются; кнопка «🔠 Текст: крупный» увеличивает шрифты ещё.
- **Как играть.** При первом запуске — 3 коротких слайда, полная справка — по `I`.

## Разработка

- Проверка синтаксиса: `for f in game.js js/*.js; do node --check "$f"; done`
- Автотест в headless Chromium (раскладки, стены, болтовня, проверки, события, пятница, маленькие экраны): `node scripts/qa.js`
- Скриншоты на 6 экранах (ноутбуки, Full HD, iPhone, Android, iPad): `node scripts/screens.js`
- Работа на своём компьютере (Windows): [docs/LOCAL_SETUP.md](docs/LOCAL_SETUP.md)
- Пересборка спрайтов из исходников: `cd scripts && python normalize_sprites.py && python make_panorama.py`
- Персонажи v3 (Быкентий, Аймашын, второй ряд): `python3 scripts/make_characters.py`
