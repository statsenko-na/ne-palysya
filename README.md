# НЕ ПАЛЬСЯ — Фирдом Риск-Офис

Офисный стелс-симулятор прокрастинации в top-down pixel-art. Главный герой — айтишник-рокер с хвостиком из отдела кредитных рисков алматинского БЦ «Угар», который должен дожить до окончания смены в 19:30. Задача — кайфовать (кофе, перекуры с видом на горы, болтовня с коллегами, чужой холодильник), но сидеть в Excel ровно тогда, когда лысый начальник смотрит в его сторону. В интерфейсе используется стилизованное название «Фирдом Банк» и эмблема без словесного логотипа.

## Запуск

- **Онлайн (GitHub Pages):** [https://statsenko-na.github.io/ne-palysya/](https://statsenko-na.github.io/ne-palysya/)
  *(первое включение: **Settings → Pages → Build and deployment → Source: GitHub Actions**; деплой идёт при пуше в `main`).*
- **Локально:** дважды кликни по `index.html`. Сборка, сервер и зависимости не нужны.
- **Телефон:** в альбомной ориентации появляются виртуальный стик и кнопки.

## Управление

| Клавиши | Действие |
| --- | --- |
| `WASD` / `ЦФЫВ` / стрелки | Ходить (стены и мебель непроходимы) |
| `E` / `У` / `Пробел` | Действие у подсвеченного места: Excel, кофе, болтовня, перекур… |
| `H` / `Р` | Спрятаться: растение, шкафы архива, ксерокс |
| `Tab` / `Q` / `Й` | Телефон: список дел, бонусы, рабочий чат (смотреть в телефон — палево) |
| `P` / `З` / `Esc` | Пауза |
| `M` / `Ь` | Звук вкл/выкл |
| `U` / `Г` | Магазин апгрейдов (в меню и после смены) |
| `B` / `И` | Альт-таб — мгновенно сделать вид, что работаешь |
| `1` / `2` / `3` | Ответ Д.Н. на летучке |
| `I` / `Ш` | «Как играть» — подробный онбординг |
| `Enter` | Начать смену / следующий день |

## Как играть

- **Конус обзора.** Жёлтый конус перед начальником — его взгляд. Прокрастинируешь в нём — растёт «?», потом «!» и залёт.
- **Excel на виду.** Если начальник рядом и видит, что ты работаешь, KPI растёт втрое, а он хвалит.
- **Коллеги.** Встань перед столом коллеги и нажми `E`. Коллеги могут прикрыть от залёта, слить расписание проверок, поправить отчёт или угостить перекусом.
- **Проверки.** «Кхм-кхм…» означает, что начальник скоро пойдёт к твоему столу или устроит рейд по этажу.
- **Второй ряд.** Соседи ноют и проёбываются. Когда начальник идёт их отчитывать, у тебя есть окно.
- **Обед 13:00–14:30** в «Мюнхене» (выход слева), туалет только через очередь, в пятницу иногда пиво.
- **События:** угощение, сбор на ДР, жара, перфоратор, пожарная тревога, летучка у доски, созвон начальника, упавший интернет, зажёванная бумага в ксероксе.
- **Автопилот 🍿 и скорость времени ⏱.** Викентий может играть сам — смотри и угорай; ползунок ускоряет время.
- **Сложность** (Стажёр / Сотрудник / Ветеран), **достижения** 🏆, стукач-стажёр, Глеб с мемами, выбор ответа на летучке, смог и пробки на Аль-Фараби.
- **Как играть.** При первом запуске — 8 слайдов с объяснениями, потом по `I`.
- **Апгрейды.** За смену дают KPI-коины, за них покупаются кресло, второй монитор, вентилятор, гитара и другое.
- **Неделя Пн–Пт.** У каждого дня свой модификатор, а в пятницу начальник уезжает «на встречу» в 17:00. Рекорды сохраняются в браузере.
- **Проигрыш:** незаметность или KPI упали до нуля.

## Разработка

- Проверка синтаксиса: `for f in game.js js/*.js; do node --check "$f"; done`
- Автотест в headless Chromium (раскладки, стены, болтовня, проверки, события, пятница, скриншоты): `node scripts/qa.js`
- Пересборка спрайтов из исходников: `cd scripts && python normalize_sprites.py && python make_panorama.py`
- Персонажи v3 (Викентий, Айаршын, второй ряд): `python3 scripts/make_characters.py`
