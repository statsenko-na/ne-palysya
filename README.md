# НЕ ПАЛЬСЯ — Фирдом Риск-Офис

Офисный стелс-симулятор прокрастинации в top-down pixel-art. Викентий, айтишник-рокер с хвостиком из отдела кредитных рисков алматинского БЦ «Угар», должен дожить до 19:30. Задача — кайфовать (кофе, перекуры с видом на Алатау, болтовня, чужой холодильник), но сидеть в Excel ровно тогда, когда лысый Директор Начальникович смотрит в его сторону. В интерфейсе используется стилизованное название «Фирдом Банк» и эмблема без словесного логотипа.

## Запуск

- **Онлайн (GitHub Pages):** [https://nikolai-statsenko.github.io/ne-palysya/](https://nikolai-statsenko.github.io/ne-palysya/)
  *(первое включение: **Settings → Pages → Build and deployment → Source: GitHub Actions**; деплой идёт при пуше в `main`).*
- **Локально:** дважды кликни по `index.html`. Сборка, сервер и зависимости не нужны.
- **Телефон:** в альбомной ориентации появляются виртуальный стик и кнопки.

## Управление

| Клавиши | Действие |
| --- | --- |
| `WASD` / `ЦФЫВ` / стрелки | Ходить (стены и мебель непроходимы) |
| `E` / `У` / `Пробел` | Действие у подсвеченного места: Excel, кофе, болтовня, перекур… |
| `H` / `Р` | Спрятаться: растение, шкафы архива, ксерокс |
| `Tab` / `Q` / `Й` | Телефон: список дел, бонусы, рабочий чат (смотреть в телефон — палево) |
| `P` / `З` / `Esc` | Пауза |
| `M` / `Ь` | Звук вкл/выкл |
| `Enter` | Начать смену / следующий день |

## Как играть

- **Конус обзора.** Жёлтый конус перед Директором — его взгляд. Прокрастинируешь в нём — растёт «?», потом «!» и залёт.
- **Excel на виду.** Если Директор рядом и видит, что ты работаешь, KPI растёт втрое, а он хвалит.
- **Коллеги.** Встань перед столом коллеги и нажми `E`. Айаршын прикроет от одного залёта, Влад сольёт календарь проверок, Александр поправит отчёт, Глеб угостит куртом.
- **Проверки.** «Кхм-кхм…» означает, что Директор скоро пойдёт к твоему столу или устроит рейд по этажу.
- **События:** угощение на кухне, созвон Директора с правлением, упавший интернет, зажёванная бумага в ксероксе.
- **Неделя Пн–Пт.** У каждого дня свой модификатор, а в пятницу Директор уезжает «на встречу» в 17:00. Рекорды сохраняются в браузере.
- **Проигрыш:** незаметность или KPI упали до нуля.

## Разработка

- Проверка синтаксиса: `for f in game.js js/*.js; do node --check "$f"; done`
- Автотест в headless Chromium (раскладки, стены, болтовня, проверки, события, пятница, скриншоты): `node scripts/qa.js`
- Пересборка спрайтов из исходников: `cd scripts && python normalize_sprites.py && python make_panorama.py`
