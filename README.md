# НЕ ПАЛЬСЯ — Фирдом Риск-Офис

Небольшая top-down pixel-art игра про Викентия, специалиста отдела кредитных рисков в алматинском БЦ «Угар». В пользовательском интерфейсе используется стилизованное название «Фирдом Банк» и отдельная эмблема без словесного логотипа.

## Запуск

- **В браузере онлайн (GitHub Pages)**: [https://statsenko-na.github.io/ne-palysya/](https://statsenko-na.github.io/ne-palysya/)
  *(Для первого включения в репозитории: **Settings** → **Pages** → **Build and deployment** → **Source: GitHub Actions**).*
- **Локально**: просто дважды кликни по `index.html` в любой ОС. Сборка, сервер и зависимости не нужны.

## Управление

- `WASD` / `ЦФЫВ` / стрелки — двигаться по офису (английская или русская раскладка)
- `E` / `У` — открыть Excel, спрятаться за ксероксом, выпить кофе, выйти на перекур или посмотреть YouTube — зависит от зоны
- `H` / `Р` — то же быстрое контекстное действие / укрытие
- `P` / `З` — пауза
- `Enter` — начать игру или перезапустить её

Директор Начальникович периодически начинает проверку. Если он идёт к твоему месту — вернись к столу, нажми `E` и дождись проверки в режиме «работает». Можно и спрятаться, но за ксероксом начальник иногда тоже смотрит.
